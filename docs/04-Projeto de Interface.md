
# Projeto de Interface

Este documento apresenta a visão geral da interação do usuário com o sistema, incluindo o protótipo interativo das telas, para as versões web e mobile, conforme o link fornecido.

O foco é na agilidade, organização e melhoria da experiência do cliente, tanto para a equipe da hamburgueria quanto para os próprios clientes.

## Diagrama de Fluxo

O diagrama de fluxo de usuário detalha a sequência de interações que um usuário realiza para completar uma tarefa específica no sistema. Ele ajuda a visualizar o caminho do usuário e a identificar possíveis pontos de melhoria na experiência. Para o sistema de caixa e gestão de pedidos, o fluxo principal envolve o login, a visualização do dashboard de mesas, o gerenciamento de pedidos e a consulta de relatórios. O fluxo para o cliente nas mesas envolve a montagem de pedido e o envio para a cozinha.

## Wireframes

A solução será desenvolvida em duas plataformas integradas:

- Plataforma Web: Destinada ao restaurante, permitindo o gerenciamento de pedidos, controle de caixa, emissão de relatórios e visualização de dashboards para análise operacional e tomada de decisão em tempo real;
- Plataforma Mobile: Voltada ao cliente, oferecendo uma interface intuitiva para realização de pedidos de forma ágil, prática e autônoma.
